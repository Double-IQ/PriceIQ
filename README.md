# PriceIQ

PriceIQ is a simple browser-based price comparison tool.

It converts each product to a common comparison unit and tells you:

- which product is cheaper;
- the normalized price for both products;
- the percentage difference;
- the saving per comparison unit; and
- the total saving if you bought the cheaper product's original quantity at the more expensive product's normalized price.

## Run it

No build step or server is required.

Open `index.html` in a browser, or serve the folder with any static web server.

## Example

With:

- Flour — 4 kg for R80
- Paint — 12 g for R15
- Comparison basis — kg

PriceIQ calculates the normalized prices and identifies the cheaper option.

## Files

- `index.html` — application markup
- `styles.css` — responsive UI
- `app.js` — comparison and savings calculations
